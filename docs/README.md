# HAProxy Docs

이 디렉터리는 목적별 번호 폴더로 문서를 관리합니다. 앞의 번호는 권장 학습 및 운영 참조 순서를 나타냅니다.

## 문서 구조

| 폴더 | 내용 |
|------|------|
| `01-installation/` | HAProxy 설치와 업그레이드 절차를 다룹니다. |
| `02-configuration/` | global/defaults/frontend/backend 등 핵심 설정 구조를 다룹니다. |
| `03-routing/` | ACL, path/header 기반 라우팅과 트래픽 제어를 다룹니다. |
| `04-load-balancing/` | 로드밸런싱 알고리즘, 헬스체크, 세션 유지 전략을 다룹니다. |
| `05-security/` | TLS, 인증, 접근 제어 등 보안 설정을 다룹니다. |
| `06-performance/` | 성능 튜닝, 커넥션, 타임아웃, 커널 파라미터를 다룹니다. |
| `07-operations/` | 로그, 모니터링, 장애 대응, 운영 절차를 다룹니다. |
| `08-extensibility/` | HAProxy 확장 기능과 외부 연동을 다룹니다. |

실행 가능한 예제와 운영 보조 자료는 [../ops/README.md](../ops/README.md)를 참고합니다.
