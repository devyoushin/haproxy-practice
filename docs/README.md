# HAProxy Docs

HAProxy 학습 문서는 주제별로 나눠 관리합니다.

| 폴더 | 내용 |
|------|------|
| `install/` | 설치와 초기 실행 |
| `config/` | 설정 파일 구조, global/defaults |
| `routing/` | frontend, backend, listen, ACL |
| `load-balancing/` | 로드밸런싱 알고리즘, 헬스체크, stick table |
| `security/` | TLS, 보안 설정 |
| `performance/` | 성능 튜닝 |
| `operations/` | 로깅, 통계, HA, Runtime API, 트러블슈팅 |
| `extensibility/` | Lua 스크립팅 |

처음 읽을 문서는 `install/01_installation_AL2023.md`입니다.
